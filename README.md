# Community Assets for Stylish Action HUD

**Note**: this project is *very* WIP. Don't expect anything to work yet.

## Intent

This project serves as a community repository of themes, adapters, and HUD presets for [The Glitch Smith's](https://www.patreon.com/cw/glitchsmith) Stylish Action HUD module for the Foundry Virtual Tabletop.

This project is not supported or managed by The Glitch Smith.

As this project takes shape, more details will be added to this README.
